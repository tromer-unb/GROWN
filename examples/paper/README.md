# Curated original scientific inputs

The folders here hold selected CIF geometries, corrected Bernal
graphite AB 100-event MACE configurations, and archived source
command-line scripts for graphene-on-substrate, defects and boron
studies. They are **examples of how the paper cases were prepared**,
not the full raw-trajectory archive. No calculations run by visiting
this folder.

**Input types are labeled:**
- The `graphite_ab` JSONs are *source 100-event input configs* whose
  file paths/PBS environment were edited strictly for portability.
- The `graphene_on_SiC`, `graphene_on_MoS2` and `graphene_defects`
  shell scripts are *actual archived commands*, not CLI-generated
  runs from a new system.
- `graphite_boron` contains the published-study source commands.
- `historical_72_case_matrix.csv` is a frozen survey snapshot;
  a running or stopped case may not reach its requested event target.

See [paper examples guide](../../docs/PAPER_EXAMPLES.md) and
[reproducibility](../../docs/REPRODUCIBILITY.md).
